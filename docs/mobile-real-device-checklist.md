## 3. 微信内置浏览器（iOS / Android 各一台）

前置：在微信里打开生产地址；不要使用微信开发者工具代替真机。

| # | 操作步骤 | 预期结果 | 实际结果 | 结果 |
|---|---|---|---|---|
| 3.1 | 打开分享链接 `#/r/...` | 只读预览正确显示标题、档位与图片 | | |
| 3.2 | 打开编辑器，点「导出 PNG」 | 弹出保存面板；有图片预览 | | |
| 3.3 | 检查面板按钮 | **没有**「直接下载」；**没有**系统分享按钮；只有「关闭」 | | |
| 3.4 | 长按预览图 | 出现微信菜单，可选「保存图片」并成功进相册 | | |
| 3.5 | 关闭面板后再次导出 | 仍然只给长按提示；不出现"已开始下载"的假成功 | | |
| 3.6 | 切到后台 30 秒再回来 | 页面不白屏；榜单内容仍在 | | |
| 3.7 | 分享当前榜单链接到聊天 | 链接可复制；对方打开后内容一致 | | |
